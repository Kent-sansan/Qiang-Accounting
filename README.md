# 记·账 v2.0

优雅的个人记账应用，使用 Flutter + Material 3 构建。

## 功能特性

- 📝 快速记账（收入/支出）
- 📊 月度/年度报表
- 💰 资产管理
- 🎨 主题切换（浅色/深色/自动）
- 📂 自定义分类
- 💾 数据导入/导出

## 技术栈

- Flutter 3.x
- Provider 状态管理
- fl_chart 图表
- SharedPreferences 本地存储

## 构建

```bash
flutter pub get
flutter build apk --release
```

## GitHub Actions

推送到 main 分支会自动触发 APK 构建，可在 Actions 页面下载。
